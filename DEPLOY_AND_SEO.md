# Публикация и SEO для septikbratsk.ru

## 1. Бесплатный хостинг GitHub Pages

1. Распакуйте архив.
2. Замените содержимое репозитория файлами из папки сайта.
3. Сделайте commit и push в ветку `main`.
4. В GitHub откройте **Settings → Pages**.
5. Выберите **Deploy from a branch**, ветку `main`, каталог `/ (root)`.
6. В поле Custom domain укажите `septikbratsk.ru`.
7. Включите **Enforce HTTPS** после выпуска сертификата.

Файл `CNAME` уже содержит `septikbratsk.ru`.

## 2. DNS домена

У регистратора домена настройте записи для GitHub Pages по актуальной инструкции GitHub. После изменения DNS обновление может занять до суток. Не удаляйте CNAME из репозитория.

## 3. Яндекс Вебмастер

1. Добавьте `https://septikbratsk.ru` в Яндекс Вебмастер.
2. Подтвердите права через DNS-запись или HTML-файл.
3. Отправьте карту сайта: `https://septikbratsk.ru/sitemap.xml`.
4. Проверьте регион сайта и укажите Братск, если инструмент предложит настройку региона.
5. Проверьте разделы «Диагностика», «Индексирование» и «Качество сайта».

## 4. Яндекс Бизнес

1. Создайте или подтвердите карточку организации.
2. Укажите тот же телефон: `+7 902 567-16-53`.
3. Укажите Братск и Братский район как территорию выезда.
4. Добавьте реальные фотографии работ, перечень услуг и цены «от», если они подтверждены.
5. Попросите клиентов оставить честные отзывы и отвечайте на каждый отзыв.
6. Добавьте ссылку `https://septikbratsk.ru` в карточку.
